# Ayman Calc

A modern calculator built with HTML, CSS and JavaScript.

## Features

- Basic arithmetic operations
- Percentage calculations
- Decimal numbers
- Delete and clear functions
- Keyboard support
- Responsive design
- Custom Ayman Calc branding
- No use of `eval()`

## Technologies

- HTML5
- CSS3
- JavaScript
